📖 接入文档

网关兼容 OpenAI / Anthropic 双协议，Codex 与 Claude Code 均可像接入方舟/千问/混元一样，只填 Base URL + Key 即可自动识别全部可用模型（模型增删后客户端自动同步，无需改配置）。

客户端/协议Base URL认证模型列表
OpenAI SDK（chat/completions）http://localhost:8000/v1Bearer KeyGET /v1/models
Codex（responses 协议）http://localhost:8000/v1Bearer Key本地目录文件（网关自动维护）
Claude Code（Anthropic 协议）http://localhost:8000Bearer Key启动时自动 GET /v1/models

API Key 在左侧 🔑 API Keys 页创建（形如 sk-...）。

🤖 Codex 接入

方式一：cc-switch（推荐）
  1. cc-switch 中添加供应商，类型选 OpenAI Codex，认证 Key 填网关的 sk-...
  2. 配置（config）填下方 config.toml 内容（model_catalog_json 指向网关自动维护的目录文件）
  3. 切换到该供应商后重启 Codex，/model 即显示全部网关模型
方式二：手动配置（~/.codex/）
  1. 创建 ~/.codex/auth.json（认证凭证）：
    {"OPENAI_API_KEY": "sk-你的Key"}
  2. 创建 ~/.codex/config.toml：
    model_provider = "custom"
model = "deepseek-v4-flash"
model_catalog_json = "/home/xiaofeiyang/.codex/model-catalog.local.json"

[model_providers.custom]
name = "modelhub"
base_url = "http://localhost:8000/v1"
wire_api = "responses"
requires_openai_auth = true
  3. 重启终端，运行 codex --version 验证；进入任意项目目录运行 codex，/model 即显示全部网关模型
💡 模型目录文件由网关在模型变更时自动重写（含描述 [厂商][模型名]），Codex 每次启动加载最新清单——无需手工维护。

🧠 Claude Code 接入

方式一：cc-switch（推荐）
  1. cc-switch 中添加供应商，类型选 Claude Code，环境变量填下方 6 项
  2. 切换到该供应商后新开终端启动 Claude Code，/model 即显示全部网关模型（含 [厂商][模型名] 描述）
方式二：手动编辑 ~/.claude/settings.json 的 env
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:8000",
    "ANTHROPIC_AUTH_TOKEN": "sk-你的Key",
    "ANTHROPIC_MODEL": "claude-deepseek-v4-flash",
    "CLAUDE_CODE_USE_GATEWAY": "1",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  }
}
⚠️ CLAUDE_CODE_USE_GATEWAY=1 是激活模型发现的关键开关（仅设 DISCOVERY 无效）；启动后 banner 显示 Cloud gateway 即接入成功。
🧹 切回其他供应商后的缓存残留：Claude Code 2.1.232 会把网关发现的模型列表缓存进 ~/.claude.json，切回 DeepSeek 等直连供应商时不清理，导致 /model 仍显示网关模型（这是客户端 bug，非网关问题）。

自动清理靠 ~/.claude_wrapper.sh：这个文件由 ~/.bashrc 里的 source ~/.claude_wrapper.sh 加载，定义了一个 claude() 包装函数——每次敲 claude 时，实际先执行清理、再启动真正的 claude，所以缓存自动被清空（幂等安全，切回网关会自动重新拉取）。这个 wrapper 同时负责会话管理：检测项目内的 .claude-session/SESSION.md，启动时用 START_SESSION.md 恢复上下文、退出时用 CLOSE_SESSION.md 自动保存进度到 SESSION.md。

手动清理：python scripts/clear_claude_model_cache.py。

🐍 OpenAI SDK（Python）

from openai import OpenAI
client = OpenAI(api_key="sk-你的Key", base_url="http://localhost:8000/v1")
r = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)

❓ 常见问题

  1. Claude Code /model 只显示几个内置模型？ —— 缺 CLAUDE_CODE_USE_GATEWAY=1（或未新开终端使 env 生效）；两个 CLAUDE_CODE 开关必须同时设置。
  2. Codex /model 只有 gpt 系列？ —— model_catalog_json 未指向网关目录文件，或 cc-switch 当前活动供应商不是本网关。
  3. 为什么 Claude Code 里模型 ID 带 claude- 前缀？ —— 网关包装用于模型发现（Claude Code 只认 claude-/anthropic- 前缀），请求时自动映射回真实模型，直接选即可。
  4. 模型增删后要改配置吗？ —— 不用。Codex 启动加载最新目录文件；Claude Code 启动时自动拉取 /v1/models。
  5. 切回 DeepSeek 后 /model 还显示网关模型？ —— Claude Code 的缓存残留 bug，网关的 claude() 包装函数已自动清理；手动清跑 python scripts/clear_claude_model_cache.py。
  6. 支持哪些模型？ —— 见左侧 🤖 模型 页实时清单（含价格与上下文）。
